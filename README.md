## 🎯 Sobre Mim

Desenvolvedor focado na concepção e implementação de soluções de software voltadas a **Sistemas de Comando e Controle (C2)**, **Planejamento Operacional Militar**, **Apoio Humanitário** e **Auditoria / Gestão de Dados Estratégicos**.

- 🔭 **Projetos Atuais:** Sistemas baseados em doutrinas do Exército Brasileiro (**EB70-MC-10.211**, **MC-5.60** e **CE 5.80 DAMEPLAN**).
- 💡 **Áreas de Especialidade:** Arquitetura Web moderna (React, Next.js, TypeScript), GIS/Exportação Geoespacial (KML, GeoJSON), pipelines de dados em Python e bancos relacionais robustos.
- 🤝 **Compromisso:** Código limpo, segurança da informação, privacidade de dados e alta aplicabilidade em operações reais.
